# GameNetworking_Spawning_DelaPena_Carl_BSEMCGD4B

Objective 
In this Activity, you will demonstrate your understanding of NetworkObject spawning and despawning by reproducing the behavior shown in the instructor's demonstration video. 

Task 
Create a Unity multiplayer project that reproduces the behavior demonstrated in the reference video.
Your project must demonstrate the following:
Your project must properly use:
NetworkManager
Unity Transport
NetworkObject
Network Prefabs
Appropriate NetworkBehaviour scripts

Object Spawning
The project must demonstrate that an object can be spawned as a NetworkObject.
The object should be:
Instantiated
Configured
Network spawned
Object Despawning
The spawned object must eventually be removed from the network.
Multiplayer Synchronization
The spawned object should behave as a networked object, not simply as a local GameObject.
Test your project using at least:
Host
Client
Verify that the networked object behaves correctly on both instances.
